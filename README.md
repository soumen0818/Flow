🧮 Calculator Smart Contract

A simple Solidity-based Calculator smart contract developed for a blockchain workshop.
It allows users to perform basic arithmetic operations — addition, subtraction, and multiplication — and retrieve the result stored on the blockchain.

🚀 Features

Add, subtract, and multiply numbers

Retrieve the current result

Fully deployed and publicly accessible on the blockchain

📜 Smart Contract Details

Language: Solidity ^0.8.30

Contract Name: Calculator

Deployed Address: 0xDaB73A6Da3D2E0843167342382C24070c8d57f14

💻 Functions
Function	Description
add(uint256 num)	Adds a number to the result
sub(uint256 num)	Subtracts a number from the result
mul(uint256 num)	Multiplies the result by a number
get()	Returns the current result
